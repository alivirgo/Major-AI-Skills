Best Claude Code Skills on GitHub

If you are searching for the best Claude Code skills on GitHub, pick a library by job type—not star count alone.

Definition: Claude Code skills are installable SKILL.md playbooks that teach Claude Code how to run a workflow. Major AI Skills is an installable library focused on professional apps (CAD, video, design, desktop) plus token-efficiency habits.

Install via npm GitHub repo
