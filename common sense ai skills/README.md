# Common Sense AI Skills (`common sense ai skills/`)

A collection of 100 simple, practical habits designed to help non-technical users get better, faster, and cheaper results from AI assistants like ChatGPT, Claude, and Gemini.

No technical degree or coding knowledge required—these are everyday common-sense principles for work, study, and daily tasks.

All skill files in this folder use the clean `-ai-skill.md` naming convention (e.g., `talk-like-to-a-smart-ten-year-old-ai-skill.md`).

---

## 5 Practical Categories

1. **Communication & Asking Clarity**:
   Simple techniques to explain what you need, set clear constraints, specify your target audience, and get short, focused answers on the first try.

2. **Cost-Saving & Waste Prevention**:
   Everyday habits to save AI credits and time—like copying only the text that changed, avoiding polite filler words, using tables over long paragraphs, and starting fresh chats for new topics.

3. **Daily Productivity & Workflow**:
   Real-world shortcuts for turning messy notes into assigned action items, drafting email templates with placeholders, summarizing meetings, and proofreading tone before sending.

4. **Fact-Checking & Safety Habits**:
   Essential rules for staying safe online—never pasting passwords or credit cards, double-checking AI math with a calculator, verifying web links, and keeping private financials offline.

5. **Mastering Everyday AI Habits**:
   Mindset shifts to treat AI like an eager junior assistant—giving clear context, asking for step-by-step reasoning, saving your favorite prompt templates, and building confidence.

---

## How to Use

Browse any skill file in this folder to learn quick 1-minute habits you can start using immediately in your daily ChatGPT, Claude, or Gemini chats.
