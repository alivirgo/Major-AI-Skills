# Codex CLI Skills

Install **Codex skills** from Major AI Skills into the Codex skills directory.

```bash
npx major-ai-skills --codex --skills docker,playwright,supabase --dry-run
npx major-ai-skills --codex --skills docker,playwright,supabase
```

Default destination: `~/.codex/skills`.

## Good starter sets

- Local app loops: `vscode`, `docker`, `playwright`
- Design handoff: `figma`, `vscode`
- Lean prompts: `csv-over-json-tables`, `ask-short-answer-first`

See also: [AI agent skills guide](ai-agent-skills.md).
