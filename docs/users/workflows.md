# Workflows

Ordered playbooks. Ask your agent to load the skills in sequence.

## Ship a SaaS Landing Page

1. `@figma` - lock layout and component contract
2. `@vscode` - implement in the repo
3. `@playwright` - smoke-test critical paths
4. `@docker` - containerize for preview
5. `@ask-short-answer-first` - keep status updates tight

## Cut a Product Demo Video

1. `@obsidian` or `@notion` - outline beats
2. `@adobe-premiere-pro` or `@davinci-resolve` - edit
3. `@adobe-after-effects` or `@remotion` - motion
4. `@ffmpeg` - export/transcode delivery masters

## CAD Revision Sprint

1. `@solidworks` or `@fusion-360` - change model
2. `@csv-over-json-tables` - compact BOM / parameter dumps for the agent
3. `@ask-short-answer-first` - review deltas only

## Knowledge Capture → Ticket

1. `@clean-messy-notes-to-action-items`
2. `@linear` or `@slack` - file work where the team lives
3. `@obsidian` - archive durable decisions
