# Major AI Skills 2.3.0

Find relevant skills without loading the entire 402-skill catalog:

```bash
npx major-ai-skills@latest --search "JSON schema business rules" --json --limit 3
```

Search runs locally, never installs skills, and returns source links and exact installation commands. It uses lexical matching, not a model or hosted search service.

- Eight passing repository tests, including eleven curated discovery queries.
- Weekly public aggregate adoption snapshots; no new installer telemetry.
- Marketplace submission packet with explicit evidence and limitations.
- Synchronized Claude, Codex, and Gemini manifests.
