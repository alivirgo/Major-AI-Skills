# Major AI Skills 2.4.0

Quality pass for the first **50 skills** in the improvement backlog (Days 1–5): thin AI-workflow stubs and high-impact product skills rewritten for production agent use, with `gpt.md` / `gemini.md` variants and plugin mirrors where applicable.

```bash
npx major-ai-skills@latest --search "RAG retrieval audit" --json --limit 3
npx skills add alivirgo/Major-AI-Skills --skill docker
```

### Highlights

- **Day 1 (AI workflows):** RAG retrieval audits, eval datasets, JSON contracts, prompt regression gates, cost/latency benchmarks, citation verification, PII redaction, human handoff, injection boundary tests, tool replay.
- **Day 2 (DevOps):** Docker, Kubernetes, Terraform, GitHub Actions, Nginx, Prometheus, Grafana, Vault, Helm, Argo CD.
- **Day 3 (Data & messaging):** PostgreSQL, MongoDB, Redis, Elasticsearch, ClickHouse, DuckDB, Snowflake, Kafka, Temporal, NATS.
- **Day 4 (Apps & automation):** n8n, Zapier, Next.js, React, FastAPI, Node.js, Playwright, Vitest, Stripe, Supabase.
- **Day 5 (Creative/CAD):** Blender, Unity, Unreal, FFmpeg, DaVinci Resolve, Figma, SOLIDWORKS, Fusion 360, Godot, Remotion.
- Tracked backlog: [`docs/skill-improvement-backlog.md`](../skill-improvement-backlog.md).

Validation, index regeneration, and marketplace sync run on publish via `prepublishOnly`.
