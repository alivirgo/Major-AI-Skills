# Geographic Information Systems (GIS) & Spatial Data Science Suite (`skills/gis/`)

This directory contains production-grade, expert-level AI Skill specifications and automation architectures for industry-standard desktop GIS platforms, spatial geoprocessing engines, cartographic composition tools, and spatial database connectors.

Each tool ecosystem includes three specialized AI engineering specifications:
- **`claude_skill.md`**: Tailored for Anthropic Claude (spatial algorithms, multi-threaded ArcPy geoprocessing, standalone PyQGIS pipelines, CRS datum shift resolution).
- **`gemini_skill.md`**: Tailored for Google Gemini (multimodal map canvas inspection, thematic symbology classification, 3D terrain scene diagnostics, ModelBuilder graphs).
- **`gpt_skill.md`**: Tailored for OpenAI GPT & Codex (Custom Python Toolboxes `.pyt`, `QgsProcessingAlgorithm` development, NumPy/GeoPandas integration, PostGIS spatial queries).
