# Game Engines & Real-Time Interactive Development Suite (`skills/game-engines/`)

This directory contains production-grade, expert-level AI Skill specifications and automation architectures for industry-standard real-time 3D and 2D game engines, procedural level design tools, physics simulators, and interactive scripting frameworks.

Each tool ecosystem includes three specialized AI engineering specifications:
- **`claude_skill.md`**: Tailored for Anthropic Claude (systems architecture, C++ entity components, GDScript statically typed controllers, JavaScript plugin monkey-patching).
- **`gemini_skill.md`**: Tailored for Google Gemini (multimodal viewport inspection, PBR shader analysis, AnimationTree state machines, Visual Profiler metrics).
- **`gpt_skill.md`**: Tailored for OpenAI GPT & Codex (Schematyc action nodes, GDExtension C++ bindings, SurfaceTool procedural generation, RPG Maker UI windows).
